## 1. 系统顶层接线（mcu_system/cmsdk_mcu_system/cmsdk_mcu_system.v）

- CPU集成层 `cortexm0integration` 对外是 **AXI-Lite主口**，信号命名：`AW_VALID/AW_READY/AW_SIZE[2:0]/AW_BURST[1:0]/AW_LEN[7:0]/AW_ADDR[31:0]/W_VALID/W_READY/W_LAST/W_DATA[31:0]/B_VALID/B_READY/B_RESP[1:0]/AR_*/R_*`（`cm0_*`前缀）
- 系统共享总线 `sys_*` = 单主直连：源码注释 **"No DMA controller - no need to have master multiplexer"** → 我们补多主仲裁的位置
- 从机风格：**SEL选择线**（`AW_SELx/AR_SELx` 由译码产生，选中才响应）；**W通道不进mux**——`W_VALID/W_DATA/W_LAST`广播给全部从机，从机按自己AW锁存的选中自行消费
- 中断分配：`intisr_cm0[5:0]=apbsubsys_interrupt[5:0]`，`[6]=apb[6]|gpio0_combintr`，`[7]=apb[7]|gpio1_combintr`，`[14:8]=apb[14:8]`，`[15]=apb[15]`，`[31:16]=apb[31:16]|gpio0_intr`，`NMI=watchdog_interrupt`

## 2. CPU集成层端口（core/cortexm0_integration/cortexm0integration.v）

参数：`BKPT/DBG/NUMIRQ(32)/SMUL(0)/SYST(1)/WIC(0)/WICLINES(34)/WPT`。除AXI主口外要点：`FCLK/SCLK/ACLK/DCLK/PORESETn/DBGRESETn/ARESETn/SWCLKTCK/nTRST`、调试（`SWDITMS/TDI/SWDO/SWDOEN/TDO/nTDOEN/DBGRESTART/DBGRESTARTED/EDBGRQ/HALTED`）、`NMI/IRQ[31:0]/TXEV/RXEV/LOCKUP/SYSRESETREQ/IRQLATENCY/ECOREVNUM`、功耗管理（`GATEHCLK/SLEEPING/SLEEPDEEP/WAKEUP/WICSENSE/SLEEPHOLDREQn/SLEEPHOLDACKn/WICENREQ/WICENACK/CDBGPWRUPREQ/CDBGPWRUPACK`）、`SE/RSTBYPASS`。内部实例化 `ahb2axi4_if`（即AHB→AXI4桥，FR-6对应项）。
**核对**：本AI未逐行核对cortexm0integration.v的端口全表，仅从cmsdk_mcu_system.v的实例化反推——**必须对照源码确认**。

## 3. 官方从机复用器（cmsdk_axi_slave_mux.v）

- 10个从机口（PORT0-9），`PORTx_ENABLE`参数开关，`DW=32`
- 主侧信号：`AW_VALID/AW_READY/W_READY/B_VALID/B_RESP/AR_VALID/AR_READY/R_VALID/R_LAST/R_DATA/R_RESP`（**无W通道**，见第1条）
- 从机侧每口：`AW_SELx/AW_READYx/W_READYx/B_VALIDx/B_RESPx/AR_SELx/AR_READYx/R_VALIDx/R_LASTx/R_DATAx/R_RESPx`

## 4. 官方地址映射（cmsdk_axi_addr_decode.v）

| 区域 | 地址 | 说明 |
|---|---|---|
| Flash | 0x0000_0000-0x0000_FFFF | 只读，固件XIP；`filename`参数→$readmemh |
| SRAM | 0x2000_0000-0x2000_FFFF | 64K |
| APB子系统 | 0x4000_0000-0x4000_FFFF | UART0-2/Timer0-1/DualTimer/WDT/测试从机 |
| GPIO0/1 | 0x4001_0000 / 0x4001_1000 | AXI GPIO |
| SYSCTRL | 0x4001_F000 | REMAP等 |
| ROM表 | 0xF000_0000 | |
| 默认从机 | 其余 | DECERR |

## 7. 存储模型（cmsdk_axi_flash.v / cmsdk_axi_sram.v）

- Flash：`#(.filename(...), .AW(16), .WS_N/WS_S(来自cmsdk_axi_memory_defs.v的宏))`，只读（写回DECERR），AR侧1拍延迟风格
- SRAM：同样参数化；字节/半字写靠 **AWSIZE+低位地址通道**（CMSDK总线无WSTRB）
- FPGA注意：flash模型是否可综合未确认 → 计划用axi_rom替代（任务15）

## 8. UART（cmsdk_apb_uart.v）

- 波特率分频寄存器（DLL/DLM或等价）、状态位（TXFULL/RXFULL）、TX/RX中断
- 固件驱动用CMSDK_driver（uart_stdout.c）；**核对**：UartStdOutInit默认的UART选择（TB注释为UART2/P1[5]）与波特率（9600）

## 9. 固件框架（software/）

- `retarget.c + uart_stdout.c`：printf→UART stdout；`hello.c`调用`UartStdOutInit()`后printf
- `startup_CMSDK_CM0.s`(GCC版)：向量表；**核对**：IRQ16对应的弱符号名（预期`IRQ16_Handler`）
- `cmsdk_cm0.ld`：FLASH 0x0 64K（rx），RAM 0x20000000 63K（rwx）——注释已为DMA结构预留空间
- 编译流程（hello/makefile）：`arm-none-eabi-gcc -mcpu=cortex-m0 -mthumb ... -T cmsdk_cm0.ld -o x.o` → `objcopy -O verilog x.hex`

## 10. 仿真TB（tb/）

- `tb_cmsdk_mcu`：实例化cmsdk_mcu，`filename="image.hex"`，`cmsdk_clkreset`给时钟复位，`cmsdk_uart_capture`捕获UART输出并在结尾`$stop`
- **坑**：TB无条件`$dumpfile("wave2.vcd")+$dumpvars` → 生成~2.3GB VCD，仿真慢（数分钟）；跑完删
- UART0↔UART1在P1引脚上回环，UART2作stdout
