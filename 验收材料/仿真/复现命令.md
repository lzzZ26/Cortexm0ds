## Q18 验收波形（非对称 / 对称）

```bash
mingw32-make -f Makefile.fir sim_tb_fir_para_impulse
mingw32-make -f Makefile.fir sim_tb_fir_para_impulse_sym
```

生成：
- `sim_out/q18_impulse.vcd` / `q18_impulse_sym.vcd`（GTKWave）
- `sim_out/q18_impulse.csv` / `q18_impulse_sym.csv`（82 个输出样本）

查看波形：

```bash
gtkwave sim_out/q18_impulse.vcd
gtkwave sim_out/q18_impulse_sym.vcd
```

输出时间：`y[n]` 在 `350 + 20n ns`，n = 0..81。
- 非对称：`y[0] = 0x16C1D27C`，`y[81] = 0xA633B39A`
- 对称：`y[0] = y[81] = 0x0004FFF6`
