# 带高阶 FIR 数字滤波器的 SoC 处理器设计

本项目是 Cortex-M0 + 自研 AXI 多主互连 + 6 通道 DMA + 支持任意非对称系数的 81 阶 FIR（82 抽头，1 sample/cycle）的 SoC 设计。

评阅与验收材料已统一整理到 **[验收材料/README.md](验收材料/README.md)**：

- **讲解文档**：[验收材料/讲解文档/](验收材料/讲解文档/)（项目总览、技术报告、PPT 大纲、讲解视频稿、指标记录、交付物清单、FPGA 说明）
- **仿真**：[验收材料/仿真/](验收材料/仿真/)（Q18 波形 VCD、输出 CSV、全部仿真图、回归/系统级日志、复现命令）
- **固件**：[验收材料/固件/](验收材料/固件/)（对称 / 非对称演示固件 hex）
- **参考资料**：[验收材料/参考资料/](验收材料/参考资料/)（官方答疑全文）

源码与仿真入口仍在仓库根目录：

- RTL：`rtl/`
- Testbench：`tb/`
- C 驱动：`sw/firmware/fir_demo/`
- 仿真：`mingw32-make -f Makefile.fir regression`
